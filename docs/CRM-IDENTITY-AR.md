## ما تغير

- لوحة ألوان مشتركة: كحلي `#10364b`، أخضر `#426d35`، accent `#95ce49`، حدود `#dce5df`، وخلفية `#f5f7f3`.
- SVG خطي 24×24 وstroke 1.65؛ لكل قسم من أقسام التنقل أيقونة واضحة بدل إعادة أيقونة Settings للأسماء غير المعرفة. Social providers تبقى رموزها المعروفة، مع معالجة لونية متناسقة داخل CRM.
- رموز لوحة الأرقام والحالات الفارغة وحالة المستند/المهمة والإضافة والإغلاق والخروج أصبحت SVG. الأيقونات الزخرفية مخفية عن قارئ الشاشة؛ أسماء الأزرار بقيت نصية، وأضيف اسم واضح لإغلاق النافذة.
- تحميل الخط العربي Tajawal محليًا من نفس الخدمة، دون طلب خطوط أو أيقونات من طرف خارجي أثناء التشغيل. الأوزان Regular 400 وMedium 500 وBold 600–900 مع `font-display:swap` وبدائل النظام.
- توحيد sidebar/cards/actions والنصوص الثانوية وحدود الحقول والتركيز وأهداف الأزرار 44px، ودعم reduced-motion وforced-colors. نموذج الطالب والعرض التجريبي يستعملان ملف الهوية نفسه؛ لا تغيير لحقول النموذج أو عدد خطواته في main.
- التغيير الوحيد في الخادم هو إضافة مسارات ملفات ثابتة محددة للهوية والخطوط وترخيصها، مع MIME صحيح؛ لا فتح مجلد عام أو تعديل مصادقة.

## الخط وترخيصه

المصدر الرسمي: `https://github.com/google/fonts/tree/main/ofl/tajawal`.

الملفات الأصلية: Tajawal-Regular.ttf وTajawal-Medium.ttf وTajawal-Bold.ttf. جرى تحويلها إلى WOFF عبر fontTools دون تغيير glyphs أو تسمية الخط الداخلية، وحُفظ SIL Open Font License الأصلي في `public/fonts/OFL.txt`.

ملفات التشغيل: `public/fonts/Tajawal-Regular.woff` (28,988 بايت)، `Tajawal-Medium.woff` (29,024 بايت)، `Tajawal-Bold.woff` (29,136 بايت). الاسم المحلي في CSS هو `Middle East Arabic`؛ لا حاجة لاشتراك أو مفتاح API.

## التحقق وحدوده

- اختبارات main الحالية: 97 اجتازت، صفر فشل أو تخطي.
- JavaScript syntax و`git diff --check` اجتازا.
- خادم محلي بقاعدة اصطناعية: الصفحة والعرض وbrand.css والخطوط والترخيص تعيد 200، والخطوط `font/woff`. واجهة بيانات CRM دون تسجيل دخول ما زالت 401.
