# خدمة العملاء وحماية بيانات الاتصال

يضيف هذا التحديث سجل متابعة موحدًا في ملف العميل، وأزرار التواصل بالقنوات المرتبطة بالفعل، وإرسال بريد من الخادم عند إعداد بريد الشركة واختباره. لا يستبدل المنصة أو يحذف بيانات قديمة.

## صلاحيات الموظف والمدير

- المدير والمالك يريان بيانات الاتصال، والموظف والمحاسب لا يتلقيان هاتف العميل أو بريده في استجابات JSON المختبرة.
- تُحجب أرقام الاتصال المعروفة بصيغها الدولية والمحلية و00 وبالأرقام العربية والفارسية، مع الحفاظ على مراجع الملفات. يشمل التنقيح القوائم والمحادثات وملفات الطلاب والحقول المخصصة والملاحظات وأسماء الملفات والنصوص المسجلة. لا يعتمد على إخفاء CSS.
- الموظف يبحث باسم الطالب أو مرجع الملف؛ البحث بالهاتف وحقول الاتصال وإنشاء/تعديل بيانات الاتصال مخصصة للإدارة. يمكنه إنشاء عميل بالاسم فقط، بينما تضيف القنوات والنماذج البيانات خادميًا.
- الإرسال يستخدم معرف العميل/المحادثة، ويحدد الخادم الوجهة من السجل. لا توجد روابط wa.me أو mailto تعطي عنوان العميل للمتصفح.
- أصول المستندات والطباعة محجوبة عن الموظف، لأنها قد تحتوي اتصالًا داخل صورة أو PDF. تبقى التصنيفات وحالات الاستلام متاحة. الأصل محفوظ للإدارة دون تغيير.
- روابط إيصالات التسجيل العامة، بما فيها القديمة، تعرض نسخة HTML منقحة من الاتصال. الأصل المخزن لم يتغير ويظل محميًا في مسار ملفات الإدارة.
- تُرفض محاولة حفظ النصوص المحجوبة أو حقول اتصال مخصصة محجوبة فوق الأصل، لمنع تلف البيانات.

هذه صلاحيات خادمية، وليست تشفيرًا جديدًا لأعمدة SQLite. قرص Render والنسخ الاحتياطية المشفرة يوفران تشفير التخزين، لكن الملف الأصلي لقواعد البيانات عند فك تشفير التخزين يحتوي الحقول اللازمة للنقل والبحث داخل الخادم. لا يمكن سحب معرفة أو صور أو مستندات حصل عليها شخص قبل تطبيق السياسة، ولا نضمن اكتشاف كل تمويه متعمد أو معلومة داخل صورة؛ لذلك حُجب الوصول للأصول.

## السجل والأزرار

يعرض الملف الملاحظات واسم كاتبها ووقتها وآخر إجراء فعلي: تحديث فرصة أو مهمة أو تسجيل أو مستند أو تجهيز رسالة. فتح الملف مسجل أيضًا مع حد تكرار خمس دقائق؛ لا يحل فتح الملف محل آخر إجراء متابعة مفيد. أحداث المزود الآلية منسوبة للنظام، دون اختلاق أن موظفًا قام بها.

WhatsApp يفتح صندوق المحادثة داخل المنصة، ويحتفظ بقواعد نافذة الرد والقوالب. Messenger وInstagram متاحان فقط عند وجود محادثة مرتبطة وحساب شركة فعال؛ لا نخمن هوية اجتماعية من اسم أو هاتف مكتوب. القنوات غير المتاحة تظهر مع سبب التعطيل.

رد حالة الملف الاختياري يعتمد على رقم WhatsApp الوارد الموقّع من المزود وربطه بالسجل. ملف واحد يحدد تلقائيًا، وعدة طلاب يحتاجون مرجعًا مملوكًا للمرسل. لا يرسل وثائق أو أرقام هوية أو روابط ملفات. يحتاج المفتاح `whatsapp_status_lookup` و`whatsapp_auto_reply` ونافذة رد مفتوحة.

## بريد الشركة

إعداد البريد للمالك فقط من داخل ملف العميل، ويشمل حساب الشركة الحالي وكلمة مرور تطبيق من المزود. الإعداد بالكامل مشفر بمفتاح الخادم داخل settings، ولا تعاد كلمة المرور للمتصفح أو سجل العمليات. لا تُشترى خدمة أو يُنشأ حساب خارجي من هذه الخطوة.

لا يصبح زر البريد فعالًا إلا بعد وجود عنوان صالح للعميل ونجاح اختبار بريد الشركة. النقل عبر Nodemailer 10.3.1، مع TLS مطلوب وشهادة صالحة، دون قراءة ملفات أو روابط أو تسجيل SMTP مفصل. الخوادم المدعومة محددة، والمنافذ 465/587 فقط. لم يُختبر مزود بريد حقيقي دون تقديم إعداداته؛ اختبار النقل الحالي بمحاكاة فقط.

الطابور دائم داخل SQLite ويعمل من عملية Render مستقلة عن Work، مع معرف طلب يمنع تكرار الضغط. يعيد التحقق من الموظف وإسناد العميل والعنوان قبل النقل. تغير العنوان أو الإسناد أو تعطيل الموظف يمنع الرسالة. قبول SMTP ليس إثبات وصول أو قراءة. المهلة الملتبسة أو إعادة تشغيل أثناء النقل ينتج عنهما `unknown` بلا إعادة إرسال عمياء.

## قاعدة البيانات والإصدار والرجوع

Migration 9 إضافة جدول customer_email_jobs وفهارسه فقط. لا يعاد كتابة بيانات العملاء أو الرسائل أو المستندات. يجب أخذ نسخة SQLite متسقة مشفرة، تتضمن server.key، واختبار استعادتها قبل النشر. بيانات إعداد البريد مشفرة داخل قاعدة البيانات وتشملها النسخة مع مفتاح الاستعادة داخل الحزمة المشفرة.

الرجوع إلى كود 0f5cc6a يوقف العامل الجديد ويتجاهل الجدول الإضافي؛ لا تحذف الجدول أو ترجع قاعدة البيانات تلقائيًا، كي لا تفقد تسجيلات أحدث. استعادة قاعدة قديمة إجراء مستقل يحتاج تقييم ما أضيف بعد النسخة. عامل البريد يضع sending المتروكة في unknown عند بدء النسخة الجديدة.

النسخة الإنتاجية المثبتة سابقًا مخزنة ومختبرة على نفس مضيف Render في مساحة مؤقتة معزولة؛ النسخ المستقل خارج Render ما زال بندًا غير مكتمل حتى التحقق من نقله واستعادته خارجيًا.

## التحقق

170 اختبارًا محليًا ناجحًا، منها 34 حالة جديدة للخصوصية وسجل العميل والبريد والواجهة. تستخدم الحالات الجديدة SQLite معزولة وجلسات اصطناعية ونقل SMTP/Meta بمحاكاة. اختبار DOM يحمّل التطبيق الفعلي ويتواصل مع مسارات HTTP المحلية: ملاحظة موظف، فتح WhatsApp من العميل، تجهيز بريد دون عنوان في المتصفح، واستمرار رؤية المدير للاتصال. لا تتضمن هذه الاختبارات إرسال رسائل لعميل حقيقي أو إثبات ربط بريد خارجي.
