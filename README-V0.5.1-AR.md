# ميد إيست — الخدمات والتسجيل 0.5.1

- قائمة موحدة تشمل 22 خدمة تعليمية منشورة، تصديق المستندات، الاستقبال والسكن، والاستشارة العامة.
- اسم الخدمة محفوظ في طلب العميل وملفه والمستند الناتج، ويظهر في سجل التسجيلات. روابط interest لم تعد تفقد نوع الخدمة.
- خدمات التوثيق والاستقبال والاستشارة تستخدم «غير دراسي» ولا تشترط شهادة أو سنة تقديم من المستخدم.
- موصل الموقع يحول روابط الطلبات القديمة والنماذج المتبقية إلى بوابة CRM، مع الاحتفاظ بالمصدر والحملة وخدمة الطلب، وإبقاء صفحات المعلومات متاحة.
- قبل استعمال النسخة المحدثة، شغّل إجراء تجهيز تطبيقات التعليم من حساب المالك؛ يضيف حقل الخدمة ويضيف «غير دراسي» دون إزالة خيارات مخصصة.
- لا تنسخ هذه النسخة بيانات Odoo التاريخية؛ تحويل وجهات الطلبات الجديدة مستقل عن ترحيل السجلات القديمة.

التحقق: 68 اختبارًا ناجحًا، بما فيها حفظ الخدمات الـ25 وربط الملفات والعميل وحماية الوصول وإعادة المحاولة دون تكرار. متطلبات الفوترة واعتماد القوالب وصلاحيات Meta تظل خارج التطبيق.
