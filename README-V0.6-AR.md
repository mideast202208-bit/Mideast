# ميد إيست 0.6 — مركز التواصل ومساعد الإدارة

## التواصل والحسابات
- صندوق موحد لواتساب وفيسبوك وإنستجرام، مع فلترة القناة والحساب والمتابعة، بحث، حالة متابعة، وقراءة خاصة بكل موظف.
- الحسابات الرئيسية الحالية تبقى كما هي. الحسابات الإضافية محفوظة مشفرة، وتحتاج مطابقة الهوية والاشتراك لدى Meta قبل التفعيل.
- الحد داخل التطبيق: 10 حسابات لكل قناة، شامل الرئيسي، أي 30 حسابًا إجمالًا. هذا حد التطبيق وليس حدًا أو ضمانًا من Meta، وليس اختبار حمل لهذا العدد.
- يدعم Facebook Pages وInstagram الاحترافي وWhatsApp Cloud API؛ لا يدير صندوق Facebook الشخصي ولا ينشر منشورات اجتماعية.
- الردود تمر من الحساب الذي استقبل الرسالة. رقم الهاتف يربط العميل مرة واحدة، مع فصل محادثات الأرقام ونوافذ الرد بينها. الصفحة لا تختلط بصفحة أخرى حتى مع معرف مرسل متطابق.
- الرد النصي للأرقام الإضافية يعمل داخل نافذة الخدمة. قوالب واتساب للأرقام الإضافية غير مفعلة حتى إضافة مسار اعتماد قوالب خاص بكل WABA؛ الرقم الرئيسي وقوالبه الحالية مستمران.

## مساعد الإدارة
- التحليل الداخلي يعمل فورًا: ملخص الشركة، المتابعات المتأخرة، الفرص الجديدة، الأرصدة حسب العملة، البحث عن ملف، ومسودات ردود قابلة للمراجعة.
- يمكن فتح العميل وتجهيز مهمة من الاقتراحات. لا ينفذ المساعد إرسالًا أو دفعًا أو تغييرًا تلقائيًا.
- محادثة OpenAI اختيارية: مفتاح مشفر واسم نموذج متاح في حساب المالك وموافقة صريحة على إرسال السؤال والإحصاءات المجمعة. لا تُرسل الملفات أو هواتف العملاء أو محادثاتهم تلقائيًا. حد 30 طلبًا خارجيًا يوميًا؛ رسوم API منفصلة.
- التحليل الداخلي محرك قواعد وحسابات مباشرة، وليس نموذج لغة. الوضع المعروض يوضح الفرق، ولا توجد مفاتيح أو فواتير AI افتراضية.

## الواجهة والبيانات
- أيقونات SVG موحدة بألوان الهوية؛ أيقونات خدمات الموقع مرتبطة بنوع الخدمة.
- قائمة جانبية منظمة، مع فصل أدوات اليوم عن إعدادات الإدارة المتقدمة.
- ترقية قاعدة البيانات إلى الإصدار 5 إضافية؛ لا تعيد إنشاء العملاء أو تمس مفاتيح الحسابات الرئيسية.
- الاختبارات تغطي تعدد الحسابات، عزل نوافذ الإرسال، الصلاحيات، توقيع Webhooks، تشفير الأسرار، وعدم إرسال بيانات العملاء تلقائيًا إلى OpenAI.

لا تمثل هذه النسخة ترحيلًا لسجلات Odoo التاريخية أو نظام محاسبة ضريبية متكاملًا. الموافقات الحية وقيود Meta وقالب إيصال التسجيل تبقى حسب حالة الحساب الفعلية.
